# hopbox documentation

hopbox is pre-release. Pages land here as each command ships:

- `getting-started.md`: install hopbox, add a host, run your first job
- `commands.md`: every command and flag
- `config.md`: the global config and the per-repo `.hopbox.toml`
- `exit-codes.md`: how to tell a failed test from a failed connection
- `agents.md`: using hopbox from Claude Code and other coding agents
- `providers/vast.md`: renting GPU machines on vast.ai
